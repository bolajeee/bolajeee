## About me

I build products end to end, from the database schema and API through to the web dashboard and the mobile app. Most of my work is for real clients and early-stage products in Nigeria: civic tech, ed-tech, logistics, agriculture, and e-commerce.

- 🏗️ Currently building **CivicAI**, an AI-driven citizen reporting platform, and **Furrow**, a home-growing app for Nigerian households
- 💼 Developer at **Leaders Network**, shipping client platforms across web and mobile
- 🤖 Interested in putting AI to practical use: classification, embeddings, semantic search, and LLM-powered workflows
- ⚙️ I care about clean architecture, type safety, and security (row-level security, dependency hygiene, CI)
